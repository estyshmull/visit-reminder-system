## סקירה כללית

המערכת משתלבת עם API של ימות המשיח לשליחת הודעות קוליות אוטומטיות למבקרים.

### תכונות עיקריות:
- ✅ שליחת הודעות קוליות בעברית
- ✅ תזכורות אוטומטיות יום לפני הביקור (בשעה 9:00)
- ✅ הודעות מותאמות אישית עם שם המבקר ותאריך הביקור
- ✅ מעקב אחר סטטוס שליחה (נשלחה/נכשלה)
- ✅ לוגים מפורטים לכל פעולה

## הגדרות

### קובץ .env
ודאי שהפרטים הבאים מוגדרים בקובץ `.env`:

```env
# Yemot HaMashiach API Configuration
YEMOT_PHONE="039219308"
YEMOT_PASSWORD="41776265"
YEMOT_API_BASE="https://www.call2all.co.il/ym/api"
ENABLE_REMINDERS=true
```

### קול ברירת מחדל
ניתן לשנות את קול ההודעה ב-`src/config/yemot.config.ts`:
- `Shira` - קול נשי (ברירת מחדל)
- `Moshe` - קול גברי
- קולות נוספים זמינים ב-API של ימות המשיח

## API Endpoints

### בדיקות ואבחון

#### 1. בדיקת משתני סביבה
```http
GET /api/reminders/debug/env
```
מחזיר את ערכי משתני הסביבה (ללא חשיפת סיסמה מלאה)

#### 2. בדיקת קונפיגורציה
```http
GET /api/reminders/yemot/config
```
מציג את ההגדרות של ימות המשיח

#### 3. בדיקת חיבור
```http
GET /api/reminders/yemot/test
```
בודק את החיבור ל-API של ימות המשיח (קבלת session token)

**תגובה מוצלחת:**
```json
{
  "success": true,
  "message": "החיבור תקין - קיבלנו session token",
  "data": {
    "sessionToken": "xxxxx..."
  }
}
```

### שליחת הודעות

#### 4. שליחת הודעת בדיקה
```http
POST /api/reminders/yemot/test-voice
Content-Type: application/json

{
  "phoneNumber": "0501234567",
  "message": "זוהי הודעת בדיקה"
}
```

### ניהול תזכורות

#### 5. קבלת כל התזכורות
```http
GET /api/reminders
```

#### 6. קבלת תזכורות ממתינות
```http
GET /api/reminders/pending
```

#### 7. שליחת תזכורת ספציפית
```http
POST /api/reminders/{reminder-id}/send
```

#### 8. קבלת ביקורים מתוכננים למחר
```http
GET /api/reminders/upcoming-visits
```

**תגובה:**
```json
{
  "count": 3,
  "visits": [
    {
      "id": "visit-123",
      "scheduledAt": "2026-01-22T10:00:00.000Z",
      "visitor": {
        "name": "משה כהן",
        "phone": "0501234567"
      }
    }
  ]
}
```

#### 9. שליחת תזכורות לכל הביקורים המתוכננים
```http
POST /api/reminders/send-upcoming-reminders
```

**תגובה:**
```json
{
  "total": 5,
  "sent": 4,
  "failed": 1,
  "skipped": 0,
  "details": [...]
}
```

## שליחת תזכורות

### תזכורות אוטומטיות (Cron)
המערכת שולחת תזכורות אוטומטית **כל יום בשעה 9:00 בבוקר** לכל הביקורים שמתוכננים למחרת.

#### איך זה עובד?
1. ⏰ בשעה 9:00 - הקרון מתעורר
2. 🔍 המערכת סורקת ביקורים למחר
3. 📞 שולחת הודעה קולית לכל מבקר
4. 📝 שומרת לוג של כל שליחה

### שליחה ידנית
ניתן לשלוח תזכורות ידנית באמצעות:
```http
POST /api/reminders/send-upcoming-reminders
```

## פתרון בעיות

### ❌ "לא הצלחנו לקבל session token"
**פתרון:**
1. בדקי שהפרטים ב-`.env` נכונים
2. בדקי שהמספר והסיסמה תקפים בחשבון ימות המשיח
3. בדקי חיבור אינטרנט

### ❌ "למבקר אין מספר טלפון"
**פתרון:**
1. ודאי שלמבקר יש מספר טלפון במערכת
2. המספר חייב להיות בפורמט: 05XXXXXXXX או 0XXXXXXXXX

### ❌ "שגיאה בשליחת הודעה"
**פתרון:**
1. בדקי לוגים בטרמינל
2. בדקי שיש יתרת שיחות בחשבון ימות המשיח
3. ודאי שהמספר תקין

### 📋 הצגת לוגים
הלוגים מופיעים בטרמינל בזמן הרצת השרת:
```
[YemotService] 📞 שולח הודעה קולית ל-0501234567
[YemotService] ✅ הודעה נשלחה בהצלחה
[RemindersService] ✅ תזכורת נשלחה בהצלחה ל-משה כהן
```

### כמה עולה כל הודעה?
לפי תעריפי ימות המשיח. בדקי בחשבון שלך.

### האם ניתן לשנות את שעת השליחה?

כן! ימות המשיח תומכת גם ב-SMS. ניתן להוסיף פונקציונליות זו.

- תאריך שליחה
- סטטוס (נשלחה/נכשלה)
- הודעת שגיאה (במקרה של כשלון)
