הסבר מפורט לשורות בקובץ `schema-new.prisma`

מטרת הקובץ: זהו קובץ סכימת Prisma חדש שמייצג את מבנה מסד הנתונים ומודלים בשכבת האפליקציה.

הסבר לפי קטעים ושורות (הערות בקובץ מקור הן בשפה האנגלית/עברית כפי שנמצאות):

1) generator client { ... }
- שורה: `generator client { provider = "prisma-client-js" }`
- מה זה: מציין ש-Prisma צריך ליצור לקוח JS (Prisma Client) עבור גנרטור זה.
- השפעה: אחרי `prisma generate` יווצר מודול `@prisma/client` לשימוש בקוד Node.

2) datasource db { ... }
- שורה: `datasource db { provider = "sqlserver" url = env("DATABASE_URL") }`
- מה זה: מגדיר את ספק מסד הנתונים (SQL Server) וכתובת החיבור שנקראת מה-ENV `DATABASE_URL`.
- מה צריך לבדוק: ודא שקובץ `.env` או משתני סביבה מספקים מחרוזת חיבור תקינה.

3) enums
- קטע: `enum AdminRole { ... }`
- מה זה: מגדיר ערכים קבועים שניתן להשתמש בהם בשדות מסוג enum במודלים (לדוגמה: `role AdminRole`).
- המלצה: אם מוסיפים ערכים חדשים, זכרו לעדכן גם הלוגיקה באפליקציה ובמיגרציות.

4) מודלים (models)
- דוגמה: `model Admin { id String @id @default(uuid()) ... }`
- מה זה: מגדיר טבלה במסד הנתונים עם שדות, מפתחות, יחסים ואינדקסים.
- שימו לב לפרמטרים: `@id` מציין מפתח ראשי, `@default(uuid())` יוצר UUID אוטומטי, `@unique` מייצר ייחודיות, `@relation` מנהל קשרים טבלאיים.

5) שדות זמן
- דוגמאות: `createdAt DateTime @default(now())`, `updatedAt DateTime @updatedAt`
- מה זה: `createdAt` שדה שנקבע לערך הנוכחי בעת יצירה; `updatedAt` מתעדכן אוטומטית בכל עדכון.

6) מיפוי שמות טבלאות/שדות
- דוגמא: `@@map("admins")` או `@map("date")`
- מה זה: משנה את השם במסד הנתונים כך ש-Prisma ישמור על שם טבלה/עמודה נתון במקום השם שנמצא בקוד.
- למה זה חשוב: שימוש במיפוי יעזור לשמור על תאימות לדאטה קיימת.

7) אינדקסים ו-unique
- דוגמאות: `@@index([phone])`, `@@unique([userId, scheduledAt])`
- מה זה: מייעל שאילתות ובדיקות ייחודיות. שים לב שלחלק מהמקרים צריך להוסיף מיגרציה כאשר מוסיפים אינדקס.

8) שינוי שבירת ברירת מחדל ל-Reminder.type
- שורה מקורית שונתה ל: `type ReminderType @default(YEMOT)`
- מה זה: ברירת המחדל עבור תזכורת חדשה תהיה `YEMOT` (הודעה קולית דרך Yemot).
- פעולה נדרשת: עדכן לוגיקה בקוד שמייצרת תזכורות כדי להתמודד עם `YEMOT` במקום `SMS`.

9) enums ספציפיים
- `ReminderType` כעת מכיל `YEMOT` ו-`EMAIL`. `YEMOT` פירושו הודעות קוליות המשודרות דרך שירות Yemot.
- אם יש טבלאות קיימות שמכילות ערכים ישנים (למשל `SMS`), תצטרכו מיגרציה שעוברת על שורות ומחליפה את הערכים הקיימים ל-`YEMOT`.

10) מיגרציות
- יש תיקיית `migrations/` בספריה. לאחר שינוי סכימה רצוי להריץ:

```powershell
# יוצר מיגרציה חדשה
npx prisma migrate dev --name update-reminder-type
# או אם לא רוצים להריץ DB local/מפתחים
npx prisma migrate deploy
```

- שימו לב: עם SQL Server יש לשים לב להרשאות ולחיבורים.

11) בדיקות
- לאחר עדכון סכימה והרצת מיגרציה, תפעילו את היישום ותבצעו בדיקות (יצירת תזכורות, קריאתן ושליחת הודעה) לוודא שהשדה `type` מטופל כמצופה.

אם תרצה, אני יכול:
- להריץ את המיגרציה המקומית ולתקן ערכי DB קיימים (אני צריך גישת DB או שתספק דטה דמה).
- ליצור ענף git חדש ולשמור שם את `schema-new.prisma` ואז למחוק את הישן.
- לייצר סקריפט SQL שמחליף `SMS` ל-`YEMOT` בטבלה `reminders` לפני הרצת מיגרציה.
